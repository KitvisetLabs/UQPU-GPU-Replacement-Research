# UQPU Hardware Research

This directory is the engineering home for hardware/device-level UQPU research.

## Structure

- `architectures/` — processor and system architectures
- `photonics/` — photonic processor and optical interconnect research
- `memory/` — QMEM/QVRAM/QHBM and classical-memory reduction
- `control/` — control/readout electronics and cryo-CMOS
- `packaging/` — chiplets, interposers, thermal and cryogenic packaging
- `physics/` — materials/device physics linked to system targets
- `models/` — hardware cost, yield, power and reliability models

All hardware work must preserve PROJECT_CHARTER.md and VERSION_INVARIANTS.md.

## Current status

Architecture/research phase. No fabricated UQPU hardware is claimed.
