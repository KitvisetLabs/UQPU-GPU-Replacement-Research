## 2. Lane A — analytic small-instance reference

Added `small_hamiltonian_reference.py` and focused tests. For a 2x2 Hermitian Hamiltonian parameterized by real diagonal entries and a complex off-diagonal entry, the helper returns row/column Euclidean norms, maximum row sparsity, analytic time evolution and a unitarity residual. Tests cover Pauli-X, diagonal degeneracy, zero time, semigroup composition and fail-closed input validation.

This is a bounded analytic reference fixture, not an algorithm. It does not instantiate a sparse oracle, reproduce the root-sparsity theorem, estimate gates or establish runtime, energy, cost or QPU advantage. The next gate remains a pinned access contract and matched algorithm-vs-reference comparisons.
