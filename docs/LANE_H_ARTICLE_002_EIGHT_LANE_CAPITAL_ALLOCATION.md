# Lane H Article 002 — Eight-Lane Capital Allocation for the Kanusanan Pongpanna Model

## Thesis
The eight research lanes should not receive equal capital by default. Funding should follow evidence maturity, mission leverage and option value while preserving all lanes.

## Proposed staged allocation logic
- Lane A receives the highest marginal R&D priority because software/cloud experiments can test the core hypothesis with the least irreversible CAPEX.
- Lanes B/C/F receive strong near-term support because cloud access, state accounting and economics determine whether A's results are real.
- Lanes D/G require patient capital because fabrication/equipment programs have longer cycles and high fixed costs.
- Lane E should prioritize low-cost experiments with clear functional requirements from D/G/infrastructure.
- Lane H maintains financing, commercialization and strategic-stage gates for the whole portfolio.

## Funding gate
A lane receives major scale-up capital only when:
1. a measurable mission dependency exists;
2. the next experiment can materially reduce uncertainty;
3. the cost of waiting is greater than the option value of learning elsewhere;
4. the result has a defined integration path.
