# Lane E Material Qualification Template

Every proposed biomass/advanced-material substitution should record:

| Field | Requirement |
|---|---|
| System function | dielectric / thermal / EMI / structural / purification / energy / recovery / other |
| Incumbent | current material/component |
| Candidate | proposed biomass-derived or alternative material |
| Required properties | numeric ranges where available |
| Candidate evidence | measured values + source/provenance |
| Process compatibility | temperature, chemistry, vacuum, cleanliness, cryogenic compatibility as relevant |
| Reliability | aging/cycling/environmental requirement |
| Lifecycle cost | incumbent vs candidate on the same functional unit |
| Evidence status | MODEL_ONLY / PUBLISHED_EXPERIMENT / IN_HOUSE_EXPERIMENT / QUALIFIED |
| Failure reason | required when rejected |
| Unlock experiment | next measurable test |

No candidate advances merely because its feedstock is inexpensive.
