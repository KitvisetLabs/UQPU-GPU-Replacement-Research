## Executive result

Batch 032 classified source-v1 D.23 as `DEPENDENCY_NOT_CLOSED`. Batch 033 independently audits the QSVT amplification step in Eqs. D214-D215.

The source first constructs a projected block approximating `A/s`, then states that QSVT applies the linear function `f(x)=s x` on `[-1/s,1/s]` with degree `O(s log(1/epsilon_2))` to recover a block encoding of `A`. The theorem statement allows `||A||<=1`, including the saturation case `||A||=1`.

Two executable checks show that this endpoint requires an additional argument:

1. the standard uniform singular-value-amplification theorem requires a strictly positive contraction margin;
2. under the direct bounded-polynomial interpretation stated below, endpoint saturation forces a degree lower bound scaling as `Omega(s/sqrt(epsilon))`.

**Classification:** `SOURCE_V1_D23_QSVT_ENDPOINT_CONTRACT_NOT_ESTABLISHED`.

This is not a claim that Lemma D.23 is false. A repaired proof may use a positive target margin, safer normalization, a different polynomial contract, spectral promises, or another amplification construction.

## 2. Standard uniform-SVA margin check

For a standard uniform singular-value-amplification route, amplification by `gamma=s` applies with a positive margin `delta` when the encoded singular values satisfy

`||A/s|| <= (1-delta)/s`.

Equivalently,

`||A|| <= 1-delta`.

Therefore the largest available margin is

`delta_max = 1-||A||`.

For the source theorem's allowed endpoint `||A||=1`,

`delta_max = 0`.

So the standard positive-margin theorem does not directly certify the endpoint case.

For comparison, if `||A||=0.9`, then `delta_max=0.1`, and the standard interior theorem can be parameterized with a positive margin.

This does not refute D.23; it shows that the displayed proof must provide a distinct endpoint-safe construction or strengthen the norm promise.

## 3. Bounded-polynomial endpoint lower bound

Consider the direct interpretation that QSVT uses a real polynomial `P` satisfying

- `|P(x)| <= 1` for all `x in [-1,1]`, and
- `|P(x)-s x| <= epsilon` for every `x in [0,1/s]`.

Let

`x0=(1-4 epsilon)/s`, `x1=1/s`.

Uniform approximation implies

- `P(x1) >= 1-epsilon`,
- `P(x0) <= 1-3 epsilon`.

The mean-value theorem therefore gives a point `xi in (x0,x1)` with

`P'(xi) >= s/2`.

Also, because the approximation guarantee holds throughout the interval,

`P(xi) >= 1-5 epsilon`.

Using the classical Bernstein-Markov inequality for a real degree-`d` polynomial bounded by one on `[-1,1]`,

`|P'(x)| / sqrt(1-P(x)^2) <= d / sqrt(1-x^2)`,

we obtain

`d >= (s/2) * sqrt(1-1/s^2) / sqrt(10 epsilon - 25 epsilon^2)`.

Hence, as `epsilon -> 0`,

`d = Omega(s/sqrt(epsilon))`.

Under this direct bounded-polynomial endpoint interpretation, that asymptotic lower bound is incompatible with a generic `O(s log(1/epsilon))` family extending all the way to the saturation endpoint.

Canonical executable examples at `s=4`:

- `epsilon=1e-4`: degree lower bound `>= 61.24489966057262`;
- `epsilon=1e-6`: degree lower bound `>= 612.3732011627744`.

The ratio of this lower bound to the diagnostic quantity `s log(1/epsilon)` grows from about `1.6624` at `1e-4` to about `11.0813` at `1e-6`; the asymptotic statement, not any fixed hidden constant, is the key point.
