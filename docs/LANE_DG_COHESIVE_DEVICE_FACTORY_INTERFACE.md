# Lane D <-> Lane G Device/Factory Interface

Lane D and Lane G now use one shared requirements contract.

For every quantum/photonic/semiconductor device concept, Lane D must provide:
- modality/device function;
- critical dimensions;
- film/material stack;
- surface/contamination limits;
- alignment/overlay needs;
- cryogenic/electrical/optical test requirements;
- package/interconnect requirements;
- target yield/reliability.

Lane G responds with:
- candidate equipment/process route;
- tool capability gaps;
- process-control/metrology plan;
- estimated throughput/yield/cost;
- automation/software requirements;
- facility/safety constraints;
- research blockers and unlock criteria.

This prevents factory-tool research from drifting away from actual chip requirements.
