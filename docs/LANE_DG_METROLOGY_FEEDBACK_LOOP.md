# Lane D/G — Metrology Feedback Loop

Lane D/G process-window co-design now requires a closed measurement loop:

device requirement -> process target -> manufacturing step -> metrology/inspection -> deviation estimate -> process-control correction -> re-measurement -> yield/reliability evidence.

Each proposed production route should eventually quantify:
- measurement resolution/uncertainty;
- sampling frequency;
- defect-detection sensitivity;
- control-latency impact;
- rework/scrap decision;
- contribution to yield and cost per good device.
