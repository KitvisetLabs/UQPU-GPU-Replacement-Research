## 2. Lane A falsification addition

The existing reference fits the restricted model (y=a x^\mu) by ordinary least squares in log space. A high in-sample (R^2) can establish a good fit within that sample; it does not establish that the pure-power-law family is correct.

A deterministic counterexample uses training points (x=(1,2,4,8,16)) generated by (y=1+x^2), which is not a pure power law. The fitted pure-power reference yields approximately:
- amplitude: 1.67614
- exponent: 1.77117
- log-space (R^2): 0.99445
- held-out prediction at (x=32): 776.576 versus true value 1025
- relative held-out error: 24.24%

The calculation was independently checked in an isolated arithmetic harness. A regression test is added to assert both the misleadingly high in-sample fit and the large held-out misspecification error.
