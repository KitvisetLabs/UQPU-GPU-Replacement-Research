# Lane E — Functional-Unit Cost Rule

Biomass/material substitution economics must be compared on an equal functional unit, not price per kilogram alone.

Examples:
- cost per square meter at required EMI shielding effectiveness;
- cost per thermal interface at required thermal resistance and lifetime;
- cost per purification cycle at specified contaminant removal;
- cost per recovered gram of critical metal at required purity;
- cost per package passing mechanical/thermal/electrical reliability.

A cheap feedstock can still be an expensive solution if processing, loading, reliability or replacement frequency is poor.

**Evidence status:** ENGINEERING/ECONOMIC FRAMEWORK.
