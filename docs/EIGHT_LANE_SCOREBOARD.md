# Eight-Lane Mission Scoreboard

## Purpose

Prevent the project from measuring activity instead of mission progress.

Each batch records one row for A–H with:
- artifacts produced;
- blockers discovered;
- evidence maturity;
- mission impact;
- next integration dependency.
