## 3. Unified mathematical language and SCM formalism

project specification for INV-037. For each goal it records linked equations,
variables/types, domain, assumptions, uncertainty rule, decision predicate,

## 4. Selected local measurements and source-bound metadata

The n=18 exact screen completed all 262,144 assignments in each of three fresh
processes. Its median elapsed time was about 2.790 s on this recorded local
environment. The n=24 exact screen evaluated 65,536 of 16,777,216 assignments
before the declared state cap and therefore cannot certify an optimum. Linux
`ru_maxrss` is reported as a fresh-process high-water mark, not incremental
solver memory.

The local atomic publish path called file `fsync`, atomic replacement and
directory `fsync`. Across 11 repetitions, median write/publish time was
104,738 ns and median post-publish read time was 8,712 ns. The read's OS cache
state was not controlled, so neither cold nor warm-cache behavior is claimed.

The official Zenodo record API reports open access and CC BY 4.0 for the dataset
associated with Putterman et al. The range protocol read the ZIP central
directory and README member only. It did not read or fit Parquet data, and the
record's published date (2024-12-03) is not a project experiment date.
