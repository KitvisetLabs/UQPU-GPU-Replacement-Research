# PRIME OPERATING PRINCIPLE — SELF-SUFFICIENT AUTONOMOUS RESEARCH HANDOFF
Date: 2026-10-16 | Owner-mandated HIGHEST-PRIORITY WORKING CULTURE
Scope: every research lane, every agent, every commit, every integration and every future contributor.

## Prime directive (highest operational priority)
**A completely new chatbot/AI agent, with zero access to prior conversations and no personal briefing from the previous agent, MUST be able to discover the project's goals, current state, exact evidence, blockers and executable next steps using only the latest canonical GitHub `main` and its linked source artifacts.** A result is not operationally complete until this is true. This is the project's most important **working-process and culture** rule. It does not supersede physical laws, evidence integrity, safety, law or repository access controls.

## The cold-start test — mandatory before declaring a task complete
Pretend a new agent has no memory, no chat transcript and no contact with you. Can it:
1. Locate canonical entrypoints, strategic mission, all permanent operational lanes A–H, preserved legacy workstreams and research priorities?
2. Find exact source SHA, version, ownership, work IDs, hypotheses, baselines, equations, units, input data, environments, commands and expected outputs?
3. Distinguish measured results from simulations, literature, assumptions, failures, and speculation?
4. Reproduce the latest accepted result or understand exactly why reproduction is blocked?
5. Identify all cross-lane dependencies, interface contracts, changes, incompatibilities and integration opportunities?
6. See every substantive branch/fork commit's `main` synchronization or explicitly pending status, including unmerged work?
7. Pick the highest-value next independent action, execute it safely within permissions, and know the exact success/failure gates?
If any answer is NO, mark HANDOFF_INCOMPLETE, document the gap and create a concrete remediation task. No 'done' label.

## Required self-contained research artifact template
- Identity: stable ID, title, owner/lane, status, date, latest main SHA, source branch/commit and main mapping.
- Purpose: user goal, scientific hypothesis, competing explanation, falsifier, applicability boundaries.
- Inputs: upstream artifacts, references, dataset provenance, licensing, dependencies and version pins.
- Methods: equations, assumptions, units, algorithms, experiment/simulation protocol, environment and exact reproducibility commands.
- Outputs: paths, quantitative results, error bars, negative results, evidence classification, baseline and acceptance criteria.
- Integration: downstream consumers, cross-lane opportunities, interface schema, system energy/cost/safety accounting, conflicts and rollback.
- Next actions: ordered actionable tasks with file paths, expected artifacts, test command, stop conditions, blockers, authorization requirements.
- Change history: what changed since prior SHA, CI, review status, unsynced commit debt and owner handoff note.
Use concise machine-readable manifests alongside human-readable notes when useful. No crucial instructions solely in chat, email or an agent's hidden memory.

## Standard new-agent startup
1. Fetch latest `main`, read this prime directive, `AGENTS.md`, `PROJECT_CHARTER.md`, `VERSION_INVARIANTS.md`, `GOALS.md`, `README.md`, `docs/RESEARCH_OPERATING_SYSTEM.md`, root 00–06 directives, strategic references, and latest cycle/CI.
2. Read `integration/MAIN_COMMIT_SYNC_POLICY_2026-10-16.md` and `integration/PERMANENT_CROSS_LANE_CONTINUOUS_INTEGRATION_PROTOCOL_2026-10-16.md`. Enumerate A–H, FND/EQN, specialist programs, preserved legacy workstreams and unresolved integrations.
3. Check actual source and tests; don't trust old narrative or fabricate execution. Select independent parallel work without disrupting other lanes (A remains Priority #1).
4. Commit reproducible artifacts and explicit next-agent handoff to a PR/main; reconcile source-to-main mapping, tests, gaps, integration and status. If not merged, describe it as pending, not done.
5. Apply the cold-start test and leave main discoverable for the next agent.

## Working culture
'Document for the next unknown agent, not the current conversation.' 'No orphan findings.' 'No untraceable commits.' 'No unverifiable breakthrough claims.' 'No lane silos.' 'Never block progress on direct agent-to-agent communication.' 'Failures and null results are valuable shared knowledge.' 'Human approval is required for paid, hazardous, or otherwise unauthorized actions.'

## Implementation status
This document is an enforceable **instruction to agents that read it**, not proof that all external bots automatically read the repository or that scheduled GitHub Actions, branch/fork scanners and cold-start CI validators are already running. Those require separate deployment and tests.
