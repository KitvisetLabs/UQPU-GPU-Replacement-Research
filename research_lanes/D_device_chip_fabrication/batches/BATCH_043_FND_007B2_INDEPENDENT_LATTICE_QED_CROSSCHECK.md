## Question

Did Batch 042 reproduce the published single-plaquette lattice-QED Hamiltonian because the implementation is genuinely correct, or could the result be an artifact of the original state-transition builder and shifted-power ground-state solver?

This gate targets implementation risk before the program moves from U(1)/QED toward SU(3)/QCD-adjacent work.

## Primary source

Michael Meth et al., **“Simulating 2D lattice gauge theories on a qudit quantum computer”**, Nature Physics 21, 570–576 (2025), arXiv:2310.12110v3, DOI 10.1038/s41567-025-02797-w.

Primary-source interfaces rechecked for this batch:

- Eq. (9a): electric term,
- Eq. (9b): magnetic / plaquette term,
- Eq. (9c): staggered matter mass term,
- Eq. (9d): kinetic pair-creation/hopping term,
- Eq. (10): qutrit electric-field and shift operators.

The source uses four matter qubits and one gauge qutrit after Gauss-law elimination for the open single plaquette. In the zero-total-charge / zero-total-magnetization sector, the physical basis has `C(4,2) * 3 = 18` states.

## Independence design

Batch 042 used:

```text
enumerate the 18-state physical basis
-> apply sigma+/sigma-/U/Udag state transitions directly
-> build the 18x18 Hamiltonian
-> shifted deterministic power iteration for the ground state
```

Batch 043 deliberately uses a different route:

```text
build local 2x2 qubit and 3x3 qutrit operators
-> tensor them into the full 2^4 * 3 = 48 dimensional Hilbert space
-> construct Eqs. (9)-(10) as dense operator algebra
-> project the full 48x48 operator into the zero-magnetization sector
-> diagonalize the resulting 18x18 real-symmetric matrix with Jacobi rotations
```

The new module does **not** import the Batch-042 Hamiltonian builder.

This creates independence at two interfaces:

1. **Hamiltonian construction:** state-transition enumeration versus full tensor-product operator algebra.
2. **Ground-state solution:** shifted power iteration versus full symmetric Jacobi eigendecomposition.

This is still one research program and one AI-assisted implementation effort. It is therefore classified as an **internal independent implementation cross-check**, not an external independent reproduction.

## Result 1 — Hamiltonian construction closes

For the frozen Batch-042 couplings

```text
g^-2 = 0.01, 0.1, 1, 10, 100
m = 0.1
Omega = 5
```

the projected Hamiltonian generated by the full tensor-product route agrees element-by-element with the Batch-042 state-transition Hamiltonian.

Maximum absolute matrix-element difference across the five tested Hamiltonians:

```text
0.0
```

Within the deterministic floating-point construction used here, the two code paths produce the same projected operator.

Because the full `18 x 18` matrices agree, the full spectra are the same mathematical eigenproblem. The independent Jacobi path nevertheless diagonalizes each matrix from scratch and freezes representative spectral values in the result artifact.

## Result 3 — numerical refinement of Batch 042 stopping rule

Batch 042 stops shifted power iteration when the **energy change** between iterations falls below `1e-13`.

The independent eigensolver shows that this criterion is sufficient for very accurate ground energies but does not force the state-vector eigenpair residual to the same scale.

Across the five frozen couplings:

- maximum ground-energy absolute difference versus the Jacobi solution: `7.531752999057062e-13`,
- maximum Batch-042 ground eigenpair residual norm: `5.333978744288818e-06`,
- maximum plaquette-expectation absolute difference: `6.715861733397333e-08`,
- squared ground-state overlap remains above `0.9999999999998` at every frozen point.

Largest observable difference occurs at `g^-2 = 1`:

```text
Batch 042 <square> = 0.5745823967558195
Jacobi   <square> = 0.5745824639144368
absolute difference = 6.715861733397333e-08
```

This is a **numerical convergence refinement**, not a physics discrepancy. The Hamiltonian itself agrees exactly between the two constructions, and the ground-state overlap is extremely close to unity.

## Interpretation

### Positive result

The experimentally grounded lattice-QED/qudit route selected in Batch 042 survives a second internal construction and eigensolver path.

This materially strengthens confidence that the Batch-042 result was not produced by an accidental state-transition convention or a single ground-state algorithm.

### Important numerical lesson

For future particle-physics gates, convergence certificates should separate:

- energy convergence,
- eigenpair residual,
- observable convergence,
- state overlap/fidelity where a trusted reference state exists.

`ENERGY_CONVERGED != STATE_VECTOR_CERTIFIED`.

That distinction becomes more important before noise studies, symmetry protection, or resource comparisons are interpreted physically.
